# 山河永驻

明末崇祯题材「王朝末期拯救」模拟游戏。玩家扮演 1627 年（崇祯元年九月）即位的朱由检，
理政、用人、征战，力挽狂澜——撑过十七年且民心、朝堂、疆域达标，即「山河永驻」。

## 运行

需要 Godot 4.x。游戏运行时只依赖 Godot 和项目内资源，不依赖 Python 或 .NET。命令行启动：

```
D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe --path "E:\沙盘推演 山河永驻"
```

资源制作工具为独立的 .NET 8 C# 控制台项目，只有在重新生成地图或 UI 素材时才需要 .NET 8 SDK：

```
dotnet run --project tools/UiAssetPrep/UiAssetPrep.csproj
dotnet run --project tools/MapGen/MapGen.csproj
```

Python 脚本仅用于开发阶段的地图生成、诊断和素材辅助，不参与游戏运行时。运行时代码（`scripts/`、`scenes/` 和 `project.godot`）不得调用 Python、读取 `.py/.pyc` 或启动外部进程。发布前可运行边界检查：

```
D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe --headless --path . --script tools/test_runtime_boundary.gd
```

## 地图口径与性能

游戏行政区模型严格采用 1627 年明代“两京十三布政使司”，共 15 个可治理区块：北直隶、南直隶及山西、陕西、山东、河南、四川、湖广、江西、浙江、福建、广东、广西、云南、贵州。行政边界以晚明万历十年（1582）《中国历史地图集》图组为基准；甘肃镇、宁夏镇、辽东都司和西海蒙古诸部属于边防/军政或羁縻区域，绘制在边防势力层，不作为普通布政使司参与内政。朝鲜、日本、蒙古、女真、安南、澜沧、暹罗、东吁、柬埔寨、吕宋和台湾等外部区域也按 1627 年历史实体命名，不直接套用现代南北韩或现代国界。1582—1627 年间发生的辽东战事和失地只覆盖势力状态，不改动法定行政边界。每个区块在 `data/provinces.json` 中保留 `historical_scope` 说明，便于事件文本和后续府州县级细化时追溯来源。当前边界几何沿用项目内现有省界数据作为绘制近似；替换为明代舆图数据后无需再改玩法逻辑。

地图生成器会在开发阶段裁剪地图框外的世界环并简化过密顶点；运行时对悬停命中检测节流并缓存标签字号。这样不会改变地图坐标或行政区 ID，却能避免鼠标移动时反复扫描数万顶点。

地图交互采用分工明确的双键：左键点击地区只打开当地信息；右键点击明方或敌占地区打开当地可执行操作（调兵布防、赈灾、整军、修城、招抚或出兵），操作作为意图交给 AI 推演。右侧不再放置会弹出方略/圣旨流程的政务按钮，改为“民心、财政、税收、灾害、战乱”五种国势视图，点击后切换地图着色并实时显示总量。

可运行区划契约检查：

```
D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe --headless --path . --script tools/test_historical_regions.gd
```

## 玩法（MVP）

- 每季度一回合，不设置季度内日回合；每季度有 **3 次行动机会**，提交本季度意图后由 AI 完成推演并自动存档（存档在 `%APPDATA%\Godot\app_userdata\山河永驻\save.json`）。
- **朝政**：颁布方略（轻徭薄赋 / 加派赋税 / 开仓赈济 / 整饬军务 / 修缮城防 / 开科取士 / 招抚流民）。
- **大臣**：明末真实人物卡牌（治政/统率/智略/忠诚/野心），任命内阁首辅与六部尚书产生月度效果；可「召见」对话。
- **军事**：舆图上点选省份，从相邻我方省份出兵光复失地，或在调兵布防。
- **事件**：阉党擅权、陕西大旱、后金入塞、闯将起事……每个事件都是真实的历史抉择。
- **败亡**：京师陷落 / 国库跌破 -300 万 / 民心 ≤5 / 疆域 ≤6 省。撑到崇祯十七年末则依据民心、朝堂、疆域评定结局。

## 大臣 AI 对话（可选）

`config.json` 填入 OpenAI 兼容接口即可让大臣由大模型扮演（默认留空时为内置台词模式）：

```json
{
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "api_key": "你的API Key",
  "model": "glm-4-flash"
}
```

支持任何 OpenAI `/chat/completions` 兼容服务（智谱 GLM、DeepSeek、Moonshot、OpenAI 等）。

## 素材

人物立绘放 `assets/portraits/<大臣id>.png` 即自动显示，缺失时使用姓氏底牌占位。
