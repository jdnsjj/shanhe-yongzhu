# 1627 明代区划资料

本项目的行政区口径以 1627 年（崇祯元年）明代制度为准。公开资料核对结果如下：

## 一级行政区

《明朝行政区划》条目明确说明，明代固定的一等民政区为“十五个一级行政区”，即两京十三布政使司：

- 北直隶、南直隶
- 山西、陕西、山东、河南、四川、湖广、江西、浙江、福建、广东、广西、云南、贵州

来源：<https://zh.wikipedia.org/wiki/明朝行政区划>

## 军政建制

辽东都司、陕西行都司、各边镇和卫所属于军政体系，不应在游戏中伪装成普通布政使司。它们可以作为边防、军事威胁或驻军层显示，但不计入“两京十三司”的内政区块数量。

来源：<https://zh.wikipedia.org/wiki/明朝行政区划>

## 历史地图底图

国学导航收录谭其骧主编《中国历史地图集》第七册（2）“明时期图组”，可用于后续替换当前现代省界近似几何：

<http://www.guoxue123.com/other/map/zgmap/014.htm>

该图组编例说明：后期全图以万历十年（1582）为准，分幅图主要以万历十年为准；其中“山东二”专列辽东都司，“陕西二”专列陕西行都司，并将甘肃、宁夏列为九边镇注记。若 1582—1627 年间没有新的一级行政区调整，1582 图组就是本项目确定两京十三布政使司行政边界的权威基准，不再用现代省界替代。

但行政边界与政治控制必须分层处理：万历后期至天启、崇祯年间辽东发生连续战事，后金取得部分城镇和土地；这些变化应进入 1627 年开局的势力、战役和失地数据，而不应反过来修改布政使司的法定边界。对 1582—1627 年间确有变化的个案，按《明史·地理志》、实录和战役记录逐条建立差异表。

## 项目采用规则

1. `data/provinces.json` 只放 15 个可治理一级行政区。
2. 甘肃镇、宁夏镇、辽东都司以及西海（青海）诸部等军政/羁縻区域通过 `data/world_regions.json` 或独立军事图层表示。
3. 事件、战斗、邻接和存档引用行政区 ID；军镇不直接作为 `province:<id>` 目标。
4. 在获得可复用的明代 GIS 边界前，现有几何只能作为绘制近似，不能宣称为府州县级精确边界。

## 1627 年外部区域口径

地图外圈同样按 1627 年政治实体标注，不直接套用现代国家名称或现代国界：

- 朝鲜半岛合并为单一区域“朝鲜王朝”，不绘制现代南北韩边界。
- 日本标为“日本（德川幕府）”；俄国只表示其西伯利亚方向势力，不能用现代俄罗斯边界解释。
- 越南在郑主、阮主分治时期，游戏以“安南诸政权”作单一区域的简化表示；老挝标“澜沧王国”，暹罗标“暹罗阿瑜陀耶”，缅甸标“缅甸东吁王朝”，柬埔寨标“柬埔寨王国”，菲律宾标“西属菲律宾”。
- 台湾在 1627 年西南部已有荷兰东印度公司据点，北部仍有西班牙势力；当前合并为“台湾（荷兰东印度公司）”单一区域，是游戏层面的简化表示，不能理解为荷兰完整控制全岛。
- 外部区域边界使用现代 GIS 海岸线的裁剪/概化几何，仅用于显示和邻接；历史控制范围由势力、事件和军事图层表达。
