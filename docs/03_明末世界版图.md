# 03 明末世界版图（1627–1644）与游戏素材点

> 用途：为《山河永驻》的外交/贸易/天下观系统提供史实底稿，并指导舆图周边（朝鲜、日本、琉球、中南半岛）的绘制。
> 年代坐标：明崇祯年间 ≈ 后金天聪至清崇德/顺治初；日本宽永锁国期；世界处于三十年战争（1618-1648）尾声。

---

## 一、东亚格局

### 1.1 后金 → 清
- 版图演变：辽东（1621 沈阳辽阳陷落起）→ 收服漠南蒙古（1635 林丹汗病逝，子降清，获「传国玉玺」）→ 1636 皇太极称帝改号大清。
- 控制链：八旗驻盛京（沈阳），五次入塞皆绕道蒙古山口；朝鲜降为藩属（丙子胡乱 1636，昭显世子入质沈阳）。
- 【游戏素材点】后金图腾系统已抽象为 jin_power；可加「漠南蒙古」事件（察哈尔归附→入塞路线解锁更多）。

### 1.2 蒙古三漠
- 漠南（察哈尔，1635 归清）、漠北喀尔喀（名义朝贡明/清之间）、漠西厄鲁特（准噶尔部正在崛起）。
- 明对蒙古贸易通道：大同/宣府马市，时开时闭。
- 【游戏素材点】马市事件：开市得马匹（军力+）但资敌；闭市省银但边患增。

### 1.3 朝鲜（李氏王朝）
- 光海君（1608-1623）在明与后金间「中立」；1623 仁祖反正（政变）亲明排金。
- 1627 丁卯胡乱、1636 丙子胡乱：清军两度破汉城，仁祖出城南汉山城投降，世子入质——明朝东亚宗藩体系崩塌的标志。
- 【游戏素材点】「朝鲜乞师」事件链（1636 前）：派援（辽东分兵，得朝鲜忠义之名+水师补给点）vs 坐视（朝鲜贡清，金无后顾）。

### 1.4 日本（德川幕府）
- 1633-1639 五次锁国令：禁止日本人出海、限长崎对华荷贸易、禁教。
- 对明关系：无正式邦交，朱印船贸易已终止；中国商人（多闽人）仍私航长崎。
- 白银出口日本→中国是明末白银第二大来源；1630s 日本限银出口后，中国白银输入收缩——**加重明末通缩**（游戏经济事件素材）。
- 【游戏素材点】「长崎银路」事件：白银流入减少→岁入被动下降（气候/白银双周期）。

### 1.5 琉球
- 两属：对明/清朝贡，同时被萨摩藩（1609 岛津氏入侵）实际控制。明末使团仍岁至。
- 【游戏素材点】装饰性外交事件（朝贡得威望小增益）。

## 二、内陆与北疆

### 2.1 乌斯藏（西藏）
- 1642 和硕特固始汗入藏建立统治，五世达赖掌政——与明无直接军政互动，仅乌思藏都司名义朝贡。
- 【游戏素材点】远期伏笔：喇嘛使团朝贡（稳定/威望）。

### 2.2 西域
- 叶尔羌汗国（察合台后裔）据天山南路；哈密早失（1514 后）。
- 「西域」在游戏舆图上留白标注即可。

### 2.3 俄罗斯
- 1632 建雅库茨克，1639 抵鄂霍次克海；1636-38 使节（莫萨维多夫等）先后与清接触前夜。
- 与明无直接接触，但 40 年后即成北方大患——可做彩蛋级远期事件。
- 【游戏素材点】「罗刹斥候」谣言事件（东北边报）。

## 三、海洋与西洋势力

| 葡萄牙 | 澳门（1573 起缴地租） | 委官黎华拿等协助铸炮；澳门铸炮厂（卜加劳）远销东亚 | **红衣大炮与炮师**来源；1628-33 明多次募澳炮队援辽 | 「澳门募炮师」事件：费银得炮术加成； Portuguese 教士（汤若望在钦天监） |

### 白银生命线（经济系统素材）
明末中国白银两大来源：美洲（经马尼拉大帆船）与日本。1630s：
- 1639 马尼拉屠华→大帆船贸易骤减；
- 日本锁国限银出口；
- → **双重打击致通缩，物价与税收体系紊乱**（明亡经济背景板）。
【游戏素材点】全局「银荒」debuff 事件（1639+）：岁入 -10%，触发条件按史实时点。

### 红衣大炮技术线（军事改革素材）
- 明军 1620s 起购/仿制红夷炮；宁远之战（1626）炮伤努尔哈赤（一说）。
- 孔有德降金（1633）后火器优势易手。
- 徐光启-孙元化练新军线是「技术翻盘」的最佳游戏改革树素材。

## 四、舆图周边补全（实现说明）

- 地图生成使用项目内 `tools/MapGen/geo/ne_world.geojson` 与中国省级 GeoJSON，由 C# 工具统一投影、裁剪和顶点概化；Godot 运行时只读取生成后的 JSON，不启动 Python 或 .NET。
- 周边政治实体写入 `data/world_regions.json`，不是明代内政区：朝鲜半岛聚合为“朝鲜王朝”，日本标“日本（德川幕府）”，蒙古/女真、俄国西伯利亚方向、安南诸政权、澜沧、暹罗阿瑜陀耶、东吁、柬埔寨和西属菲律宾分别标注。
- 辽东都司、西海蒙古诸部、亦力把里、乌斯藏都司以及台湾外部势力单独绘制在边防/外部层。台湾条目明确是荷兰东印度公司控制的简化表示，不能解读为荷兰完整控制全岛；琉球暂以历史注记保留，因底图没有稳定的独立多边形。
- 同一历史实体由多个现代几何组成时（例如朝鲜南北两块、南直隶和湖广），生成阶段先做几何并集，避免现代国界或省界接缝冒充 1627 年历史边界。所有外部轮廓仍属于显示近似，真实控制范围由势力、事件和军事图层表达。
