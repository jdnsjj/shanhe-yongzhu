## 二、核心玩法循环

```
看国势 → 接时政任务 → 问大臣 → 用自然语言写诏书 → AI 推演 → 世界数值变化 → 新危机
```

- **没有预设事件树**：满朝文武、流民义军、后金势力全部由大模型实时反应。
- 玩家行为自由度极高：有玩家 70 小时从工业革命攀科技「造出原子弹」，制作组接受这种「玩家靠努力达成目标」。
- 制作人对「AI 原生」的定义：*把这个模块剥离出去，核心玩法还能不能玩*。

## 三、技术架构（对我们最有参考价值）

1. **步进式状态机**：每回合只保存前一状态 + 增量修改（区别于普通 AI 文游的超长上下文框架）。
2. **推演三层**：
   - **状态约束**：推演结果必须符合历史与当前数值；
   - **意图判断**：修仙类「整活」诏书通常结果不好（不完全驳回——「一部分实现、做到一半、计划好但执行不下去」）；
   - **故事转数据**：LLM 叙事转成结构化数据写库，世界状态修改 benchmark 要求 **99%+ 成功率**（单测跑 100 次）。
3. **放弃 RAG**：效果不佳，改为「数值区间理解 + 硬性数值框架」（如民心归 0 触发投叛军感知模块）。
4. **模型选型**：效果/成本/速度「不可能三角」，认为 DeepSeek、通义千问系列合适。
5. **已知问题**：同一存档重复推演细节有差异（抄家 100 万两 vs 150 万两）；长局记忆偏差；服务器崩溃事故。

## 五、玩家评价双清单

**差评 Top5**（对应差评占比最高优先）
1. 先买后内购（Token）——「开创单机坏先河」「3 回合 20 块」
2. AI 推演不确定：逻辑不一致、长局记忆偏差、细节漂移（抄家 100 万 vs 150 万两）
3. 设定偏阴谋论、明史考据不足
4. 稳定性：服务器崩溃、Token 用尽导致回合失败
5. 更新质量下滑感

**好评 Top5**
1. 自由度传统游戏无法实现（「AI 游戏是未来」）
2. 数值硬核
3. 对话/奏疏与史实结合，代入感强（「大臣说的话对不上史实时，你玩到真崇祯了」）
4. 粘性数据佐证（日均 7 小时）
5. 满朝文武皆 AI 的新鲜感
