## 最新玩法约束（优先于下文旧重构记录）

- 正式玩法全 AI 驱动。无 API 配置时不再调用离线推演或本地大臣回复。

- 季度 AI 负责旧任务进度、阻碍、后续目标及新任务生成；聊天和草稿不算执行完成。
- AI 失败不推进季度，已颁圣旨保留以便重试。离线领域实现仅暂留作旧测试辅助。
- 本轮尚未做真实服务长局与视觉验收；初始根任务仍为开局设定，后续任务由季度 AI 生成。

## 二、架构与依赖红线

```
app/src/
  domain/     纯 TS：types, constants, schemas(zod), state, pipeline, transition, offline
  ai/         纯 TS：client(缓存/去重), prefixes(提示词), operations
  map/        纯 TS：geometry, camera, hittest, viewmodes
  persist/    纯 TS：migrate(Godot v5), storage(Memory/LocalStorage/Tauri)
  components/ React：MapView(Canvas), Hud, Dialogs
  store.ts    zustand 桥接
app/src-tauri/  Rust：窗口 + fs/dialog 插件（极薄，无业务逻辑）
```

**红线**：`domain/`、`ai/`、`map/`、`persist/` **不得** import React / Tauri / 浏览器 API。
由 Vitest 在 `environment: 'node'` 下运行来客观保证。新增领域代码若在 Node 下测试失败，说明越界了。

## 七、技术备忘（新对话必读）

- **包管理**：一律用 `pnpm`（本机 11.7.0）。`pnpm install` 在 `app/` 下执行。
- **PowerShell 显示中文会乱码**：读文件请用 read 工具，不要用 `Get-Content` 输出中文。
- **Rust 首次编译约 14 分钟**（Tauri 依赖树约 600 个 crate）；增量编译很快。超时请用后台任务。
- **Vite 监听崩溃**：不要把浏览器 profile 等频繁变动的目录放进项目树，会导致 `EBUSY` 崩溃
  （已在 `vite.config.ts` 的 `server.watch.ignored` 加了兜底）。
- **无头验收**：`node tools/verify-flow.mjs http://localhost:5199/`（需先 `pnpm exec vite preview --port 5199`；CDP 端口可用 `DSH_CDP_PORT` 覆盖，Edge profile 按端口隔离）。当前机器 Edge 启动会挂起，复验需先确认 `msedge.exe --version` 能正常返回。
- **勿把 `config.json` 加进 `dist`**：Vite 插件只做开发期挂载，这是有意的密钥保护。
- **领域命名**：`publicSupport`=民心（旧 `pop`），`militaryMorale`=军心（旧 `morale`）；
  `tax` 是税基权重，`garrison` 单位是万。
- **提示词**：`ai/prefixes.ts` 中 12 段 system 提示词是**逐字移植的语义契约**，不要改写。
- **常量**：`domain/constants.ts` 的数值与旧实现逐字一致，改动会影响存档兼容。
